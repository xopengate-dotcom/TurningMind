# TurningMind – Gestione Intelligente Turni Bar/Ristorante

Applicazione web per la gestione automatizzata dei turni di un bar/ristorante.

## Stack
- Frontend: React + Vite + TypeScript
- Backend: Firebase (Auth + Firestore)
- Solver: Google OR-Tools
- LLM: Gemini API

## Setup
1. Copia `.env.example` in `.env` e inserisci le chiavi Firebase
2. `cd frontend && npm install && npm run dev`
